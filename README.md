# Apple MacBook Website

Built with modern web technologies — React, Three.js, GSAP, Tailwind CSS, and Vite — this immersive 3D website showcases an Apple MacBook in an interactive, scroll-animated experience. 

# Live Demo
**Check it out here:** [Apple MacBook Website](https://apple-website-two-delta.vercel.app/)

# Features 

👉 3D Product Scene with Realistic Lighting System: Showcased products in lifelike 3D environments for maximum visual impact.

👉 Animated 3D Models on Scroll: Created immersive interactions by animating 3D models based on user scroll position.

👉 ScrollTrigger Effects: Implemented scroll-based animations and timeline control using GSAP’s ScrollTrigger.

👉 Pinned Sections: Designed locked sections that stayed in view while animating content for engaging scroll experiences.

👉 Image Masking Effects: Applied scroll-triggered pins and masks for visually striking image transitions.

👉 Seamless Timeline Animations: Crafted smooth animation timelines that spanned multiple sections.

👉 Responsive Design: Ensured a fluid user interface and adaptive GSAP animations across all screen sizes.

# Quick Start

Follow these steps to set up the project locally on your machine.

Prerequisites

Make sure you have the following installed on your machine:

- Git
- Node.js
- npm (Node Package Manager)
  
Cloning the Repository

```bash
git clone https://github.com/Rites23/Apple-Website.git
```

Installation

Install the project dependencies using npm:

```bash
npm install
```
Running the Project

```bash
npm run dev
```

Open http://localhost:5173 in your browser to view the project.
